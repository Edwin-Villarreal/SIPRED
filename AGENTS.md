# SIPRED project guidance

- Build SIPRED in the requested phases; do not implement physical hardware before it is selected.
- Preserve the official logo and palette. Never invent or redraw a replacement logo.
- Keep device authentication separate from browser user sessions.
- Keep the app configured for MySQL/InnoDB; PHPUnit uses the SQLite in-memory connection from phpunit.xml.
- Add dependencies only when needed for the phase being implemented.
- Keep documentation in Spanish and clearly label unfinished modules and demo data.
